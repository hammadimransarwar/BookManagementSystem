# Book Management System

A C# Console Application for managing books using file handling.

## Features

- Add a book
- View all books
- Find a book by ID
- Create a backup of books.txt
- Exit the program

## Technologies

- C#
- .NET
- FileStream
- StreamReader
- StreamWriter
- List<T>

## Files

- Program.cs
- Book.cs
- BookDataAccess.cs
- books.txt
- books_backup.txt
